QUICK START (5 MINUTES)
─────────────────────────────────────────────────────────────────────────────

Step 1: Install Ollama
  Download from https://ollama.ai
  Run: ollama run gemma
  (Leave this running in Terminal #1)

Step 2: Install Python Dependencies
  pip install -r requirements.txt

Step 3: Start Backend
  python app.py
  (Leave this running in Terminal #2)

Step 4: Open Browser
  Go to: http://localhost:5000
  Press the big button 🎤
  Talk!

WHAT IT DOES
─────────────────────────────────────────────────────────────────────────────

1. Press button → Hold while speaking
2. AI listens → Whisper transcribes → Gemma extracts reminder
3. Reminder appears in list
4. Check it off → Fades away → 10-second undo window
5. After 10 seconds → Gone forever (intentional)

TROUBLESHOOTING
─────────────────────────────────────────────────────────────────────────────

Problem                  → Solution
─────────────────────────────────────────────────────────────────────────────
"Ollama not running"     → Run: ollama run gemma (Terminal #1)
"Backend not running"    → Run: python app.py (Terminal #2)
Microphone won't work    → Allow localhost:5000 mic permission in browser
App is slow (first run)  → Whisper downloads 75MB model (~30 sec), then fast
Reminders are gibberish  → Speak more clearly, shorter sentences
